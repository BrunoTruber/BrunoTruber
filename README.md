  ## Sobre mim

  Sou desenvolvedor full stack, atuando profissionalmente no desenvolvimento e na manutenção de aplicações web com Java, Spring Boot, Angular e TypeScript.

  No backend, trabalho com APIs REST, PostgreSQL, Redis e ambientes conteinerizados com Docker. No frontend, atuo na construção e manutenção de interfaces com Angular e TypeScript.

  Paralelamente, estudo o ecossistema Microsoft por meio de cursos e projetos pessoais, utilizando C#, .NET, ASP.NET, SQL Server, Visual Studio e SQL Server Management Studio.

  Atualmente, busco evoluir em arquitetura de software, testes automatizados, segurança de APIs e construção de aplicações escaláveis e de fácil manutenção.
